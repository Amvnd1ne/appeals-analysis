# Анализ обращений пользователей

Веб-приложение для хранения, обработки и анализа обращений пользователей. Позволяет вести учёт обращений, искать и фильтровать их, строить аналитические графики и выгружать отчёты.

## Возможности

- Хранение обращений в SQLite (дата, текст, категория, пользователь, статус)
- Просмотр списка обращений с пагинацией
- Просмотр подробной карточки обращения
- Поиск по тексту и фильтрация по категории
- Категоризация обращений (6 предустановленных категорий)
- KPI-показатели: всего обращений, за 7 дней, топ-категория, доля решённых
- Интерактивные графики (Plotly):
  - распределение по категориям (пончик)
  - динамика по дням за 30 дней (столбчатая)
  - топ-10 самых частых проблем (горизонтальная)
- Экспорт всех обращений в CSV
- REST API для интеграции:
  - `GET /api/stats` — агрегированная статистика в JSON
  - `GET /api/appeals?q=&category=&limit=` — список обращений с фильтрами
- Автоматические тесты (8 штук, pytest)

## Стек

- **Python 3.14**
- **Flask 3.1** — веб-фреймворк
- **SQLite** — база данных
- **pandas 3.0** — анализ данных
- **Plotly 7.1** — визуализация
- **Bootstrap 5** — вёрстка
- **pytest** — тестирование
